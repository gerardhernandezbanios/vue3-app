# Strava Dashboard

Frontend para explotación de datos Strava con Vue 3 + Vuetify.

## Requisitos

- Node 18+
- pnpm

## Comandos

- `pnpm install`
- `pnpm dev`
- `pnpm build`
- `pnpm lint`
- `pnpm format`

## Estructura

- `src/` código fuente
- `src/components/ui` componentes atómicos
- `src/views` vistas por dominio
- `src/services` adaptadores API
- `src/stores` Pinia
